Classification / Fraud Detection
Credit Card Fraud Detection

Detected fraudulent transactions in a highly imbalanced dataset (284,807 transactions, only 0.17% fraud) using SMOTE oversampling and comparing Logistic Regression against Random Forest.

Random Forest: 92% precision, 75% recall — visualized in a Power BI fraud-risk monitoring dashboard.

Time Series Forecasting
Walmart Sales Forecasting

Forecasted Walmart's weekly sales using seasonal decomposition and Holt-Winters exponential smoothing, benchmarked against a seasonal-naive baseline and evaluated with Walmart's own WMAE metric.

Found that a simple baseline can outperform a more complex model when historical data is limited — an honest, data-driven conclusion over a "fancier model wins" narrative.
Python Statsmodels Time Series Excel

NLP / Text Classification
IMDb Sentiment Analysis

Classified 50,000 IMDb movie reviews as positive or negative using TF-IDF vectorization, comparing Logistic Regression against Naive Bayes for automated review monitoring at scale.

Logistic Regression: 89.2% accuracy — explored via an interactive Tableau dashboard with sentiment and confidence breakdowns.
Python NLTK TF-IDF Tableau

Unsupervised Learning / Clustering
Mall Customer Segmentation

Segmented mall customers into distinct personas using K-Means clustering on income and spending score, with the elbow method used to select the optimal number of clusters.

5 business-ready personas identified (e.g. "Prime Targets", "Budget Conscious") to guide targeted marketing strategy.
